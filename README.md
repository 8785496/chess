# Шахматы — PWA (React + TypeScript)

Клиентское шахматное веб-приложение по [PLAN.md](./PLAN.md): игра против бота
(Stockfish WASM), подсказки, разбор партий, библиотека классических дебютов,
мобильная вёрстка и офлайн-режим (PWA). Бэкенд не нужен.

## Возможности

- ♟ **Полные правила** (chess.js): рокировка, взятие на проходе, превращение пешки
  (диалог выбора фигуры), мат/пат, ничьи (50 ходов, троекратное повторение,
  недостаток материала).
- 🤖 **Игра против бота** — Stockfish 18 (lite-single, однопоточная сборка без
  SharedArrayBuffer/COOP-заголовков), 5 уровней: `UCI_Elo`/`Skill Level` + лимиты
  глубины и времени. Движок изолирован в Web Worker и догружается лениво.
- 💡 **Подсказка хода** (стрелка + оценка) и **живая шкала оценки**.
- 🔍 **Разбор партии**: прогон истории через движок, классификация ходов
  (лучший/отлично/хорошо/неточность/ошибка/зевок), аннотации в списке ходов,
  переход по позициям, режимы «быстро/точно». Завершённые партии открываются
  для разбора прямо из истории (главный экран), итоги — точность и число зевков —
  сохраняются в записи истории.
- 📖 **Библиотека дебютов ECO**: 116 классических линий (все валидированы тестами),
  поиск, пошаговый плеер с автоплеем, определение варианта по ходам,
  «играть с этой позиции против бота».
- 🧩 **Шахматные задачи**: 197 головоломок — маты в 1–4 хода и тактика
  (вилки, протыкание, отвлечения). 17 классических задач составлены вручную
  (детский мат, партия из Оперы, двойной шах Рети — в том числе за чёрных,
  «наследие Филидора» со спёртым матом), ещё 180 отобраны из открытой базы
  Lichess (CC0) скриптом `scripts/generate-puzzles.mjs`. Фильтры по статусу
  решения и по числу ходов. Ходы проверяются на доске: неверный ход не
  засчитывается, соперник отвечает автоматически, а в матовых задачах
  принимается любой ход, сохраняющий форсированный мат. Прогресс и число
  ошибок сохраняются. Датасет валидирован тестами (легальность,
  форсированность матов, выигрыш материала); для матов на 3–4 хода
  форсированность доказывается прогоном Stockfish (`puzzles.engine.test.ts`).
- 📱 **Мобильная вёрстка**: доска вписывается в экран, safe-area, touch-жесты
  (drag & drop и tap-to-move), блокировка скролла при перетаскивании.
- 📴 **PWA**: установка на домашний экран, офлайн после первого визита
  (precache app shell + runtime-кэш WASM движка).
- 🎨 Темы доски, тёмная/светлая, звуки (WebAudio-синтез, без файлов), i18n RU/EN,
  история партий и настройки в localStorage, экспорт PGN/FEN.

## Стек

Vite 8 · React 19 · TypeScript (strict) · Tailwind CSS 4 · Zustand ·
chess.js · react-chessboard v5 · stockfish (WASM) · vite-plugin-pwa ·
Vitest + React Testing Library · ESLint + Prettier.

## Скрипты

```bash
npm ci        # установка + копирование движка и генерация иконок
npm run dev   # дев-сервер
npm run build # typecheck + продакшн-сборка (dist/)
npm run preview
npm test      # vitest (unit + component)
npm run lint
npm run format
```

## Архитектура

```
src/
  core/        # обёртка chess.js, классификация ходов, звуки
  engine/      # UCI-адаптер Stockfish, уровни бота, менеджер воркера
  board/       # обёртка react-chessboard, диалог превращения
  features/
    game/      # экран партии: доска, ходы, шкала оценки, разбор
    puzzles/   # шахматные задачи: каталог, решатель, форсированный мат
    openings/  # каталог ECO + пошаговый плеер
    settings/  # настройки, история
  stores/      # zustand: game, settings, history, engine
  data/        # openings.json (116 линий), puzzles.json (197 задач)
  i18n.ts      # RU/EN словари
```

Движок — один Web Worker (`public/engine/`, копируется из `node_modules/stockfish`
скриптом `scripts/copy-engine.mjs`), задачи (ход бота / подсказка / разбор)
выполняются последовательно через менеджер. Позиция партии — единственный
экземпляр chess.js в сторе; UI — чистая проекция.

Пополнение каталога задач: скачать `lichess_db_puzzle.csv.zst` с
[database.lichess.org](https://database.lichess.org/#puzzles) в `data/lichess/`,
распаковать `python scripts/decompress-puzzles.py` (нужен pip-пакет
`zstandard`), затем запустить `node scripts/generate-puzzles.mjs` — скрипт
отфильтрует базу по популярности и темам, проверит линии через chess.js и
Stockfish и допишет задачи в `src/data/puzzles.json`.
